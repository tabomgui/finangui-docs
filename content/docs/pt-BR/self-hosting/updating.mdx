---
title: Atualização
description: Como atualizar uma instância self-hosted para uma versão mais nova.
---

Atualizar uma instância self-hosted significa buscar o código mais recente e reconstruir a stack do Compose:

<Steps>
<Step>
### Busque o código mais recente

```bash
git pull
```
</Step>

<Step>
### Reconstrua e reinicie

```bash
docker compose -f docker-compose.prod.yml --env-file backend/.env up -d --build
```

Isso reconstrói qualquer serviço cuja imagem mudou e reinicia a stack já com o código novo.
</Step>
</Steps>

<Callout type="info">
  As migrations rodam automaticamente no início, como já coberto em [Instalação](/docs/getting-started/installation) — não existe um passo separado de migration para rodar depois de uma atualização.
</Callout>

Faça backup do banco de dados antes de atualizar se a mudança for grande ou se você estiver saltando várias versões de uma vez — veja [Backup](/docs/self-hosting/backup).

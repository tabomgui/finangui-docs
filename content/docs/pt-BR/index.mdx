---
title: Introdução
description: finangui é um gerenciador financeiro pessoal self-hosted, com backend Laravel + Postgres e frontend React.
---

finangui é um gerenciador financeiro pessoal self-hosted. O backend é uma API Laravel 13 sobre Postgres, o frontend é React/Vite/TS, e tudo roda em Docker. Dinheiro é sempre guardado como centavos inteiros, nunca como float, e valores derivados como saldos e totais são sempre calculados no backend — nunca gravados, nunca calculados no frontend.

<Callout type="info">
  A interface do app é em português do Brasil. Esta documentação mantém os rótulos da interface na forma original, em negrito, com o significado em inglês entre parênteses na primeira aparição. Por exemplo: **Configurações** (Settings).
</Callout>

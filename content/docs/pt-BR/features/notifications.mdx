O ícone de sino mostra coisas que o finangui considera importante — uma folha (sheet) no celular, um popover no desktop. Clicar leva direto para a tela correspondente.

## Os quatro tipos de alerta

- **Fatura vencendo** (invoice due) — uma fatura se aproximando do vencimento. Veja [Cartões](/docs/features/cards).
- **Orçamento estourado** (budget exceeded) — uma categoria acima do limite mensal. Veja [Orçamento](/docs/features/budgets).
- **Lançamentos pendentes** (pending entries) — uma recorrência atrasada e não confirmada. Veja [Recorrências](/docs/features/recurrences).
- **Reconexão necessária** (reconnection needed) — uma conexão precisa de credenciais atualizadas. Veja [Integração bancária](/docs/features/banking).

<Callout type="info">
  Os três primeiros são checados uma vez por dia, um resumo por tipo. A reconexão dispara na hora, durante uma sincronização.
</Callout>

## Deduplicação e limpeza

- O mesmo alerta nunca dispara duas vezes para a mesma coisa.
- Notificações lidas com mais de 90 dias são apagadas automaticamente.

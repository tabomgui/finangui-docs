title: Orçamento

---

Um orçamento é um limite mensal de gasto numa categoria. **Orçar categoria** (budget a category) abre o formulário — só despesa, nunca receita, transferência ou arquivada.

![A tela Orçamento](/screenshots/budgets.png)

## Padrão e exceções

- O valor informado é o padrão para todo mês.
- **Vale para** (applies to) sobrescreve só o mês visto.
- Exceção ativa mostra o selo **Só este mês** (only this month).

<Callout type="info">
  **Sem orçamento só neste mês** cancela só aquele mês — o padrão e a exceção continuam.
</Callout>

## Categorias pai e filha

- Orçar o pai cobre ele e todas as subcategorias.
- Gasto de filha conta para o pai mesmo sem estar orçada.
- Uma filha ainda pode ter limite próprio.
- Totais nunca contam o gasto de uma filha em dobro.

## Gasto, restante, progresso

- Cada linha: barra de progresso e percentual.
- O gasto é líquido (saída menos estorno), nunca negativo.
- Ao passar do limite, "restam" muda para "excedeu".
- O gasto não orçado aparece separado, como **Fora do orçamento**.

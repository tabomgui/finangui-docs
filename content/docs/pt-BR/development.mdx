title: Desenvolvimento
description: Rode o finangui localmente com Docker para desenvolvimento, e os targets do make que cobrem o dia a dia.
---

O finangui é uma API Laravel 13 com Postgres (`backend/`) e um frontend React/Vite/TypeScript (`frontend/`). Tudo — banco de dados, backend, frontend, worker de fila e scheduler — roda em Docker, orquestrado por um `Makefile` na raiz do repositório.

## Requisitos

- Docker
- Make

## Subindo a stack

<Steps>
<Step>
### Crie o arquivo de ambiente do backend

```bash
cp backend/.env.example backend/.env
```
</Step>

<Step>
### Suba os containers

```bash
make up
```

Isso sobe o banco (`:5432`), o backend (`:8001`), o frontend (`:5174`), o worker de fila e o scheduler. As portas do backend e do frontend podem ser trocadas por `BACKEND_PORT` e `FRONTEND_PORT`.
</Step>

<Step>
### Gere a chave da aplicação

```bash
make art c="key:generate"
```

`make art` roda qualquer comando `php artisan` dentro do container do backend.
</Step>

<Step>
### Migre e crie um usuário de desenvolvimento

```bash
make fresh
```

Isso migra o banco do zero e cria um usuário de desenvolvimento: `dev@finangui.test` / `password`.
</Step>
</Steps>

<Callout type="info">
  A documentação interativa da API (Scramble) fica em `http://localhost:8001/docs/api` — só disponível enquanto `APP_ENV=local`; em qualquer outro ambiente a rota fica bloqueada.
</Callout>

## Targets do make no dia a dia

| Target | O que faz |
| --- | --- |
| `make up` | Sobe `db` (`:5432`), `backend` (`:8001`), `frontend` (`:5174`), o worker de fila e o scheduler. |
| `make art c="..."` | Roda um comando `php artisan` dentro do container do backend, ex.: `make art c="key:generate"`. |
| `make fresh` | Migra o banco do zero e cria um usuário de desenvolvimento (`dev@finangui.test` / `password`). |
| `make test` | Roda a suíte de testes Pest contra o banco `finangui_test`. |
| `make lint` | Roda Pint e Larastan no backend. |
| `make openapi` | Gera o schema OpenAPI em `backend/storage/app/openapi.json`. |
| `make types` | Regera o cliente tipado da API no frontend (`frontend/src/api/schema.d.ts`) a partir desse schema OpenAPI. Rode depois de mudar a API. |
| `make front-check` | Roda lint, typecheck e a suíte de testes do frontend. |

<Callout type="warn">
  `make test` roda contra um banco separado, `finangui_test`, criado por `docker/postgres/init.sql` na primeira vez que o volume `db-data` é inicializado. Se esse volume já existia antes do `init.sql` ganhar esse banco, ele não é criado automaticamente — recrie o volume (`make down && docker compose down -v`, que destrói dados de dev) ou crie-o à mão: `docker compose exec db createdb -U finangui finangui_test`.
</Callout>

## Reconstruindo containers

O frontend também roda em container (já sobe com `make up`), mas o editor e as ferramentas de TypeScript (checagem de tipos, oxlint) precisam das dependências instaladas no host também:

```bash
cd frontend && npm install
```

Se `frontend/package.json` mudar, a imagem do frontend precisa ser reconstruída — só reiniciar o container não é suficiente:

```bash
docker compose build frontend && docker compose up -d -V frontend
```

O mesmo vale para o backend quando algo em `docker/php/**` muda (ex.: `uploads.ini`, o `Dockerfile`):

```bash
docker compose build backend && docker compose up -d -V backend
```

## Contribuindo

O finangui é um repositório público no GitHub. Contribuições seguem o fluxo padrão: fork, branch, pull request.

Para as convenções reais do projeto — estrutura de pastas por domínio, a regra de dinheiro em centavos, TDD com Pest, e tudo mais que rege como o código é escrito aqui — veja o `CLAUDE.md` do próprio repositório, na raiz do projeto. Ele é a fonte da verdade dessas regras e é mantido atualizado conforme o código evolui; duplicá-lo aqui só ficaria desatualizado com o tempo.

O finangui é uma API Laravel 13 com Postgres (`backend/`) e um frontend React/Vite/TypeScript (`frontend/`). Tudo roda em Docker, orquestrado por um `Makefile` na raiz do repositório.

## Requisitos

- Docker
- Make

## Subindo a stack

<Steps>
<Step>
### Crie o arquivo de ambiente do backend

```bash
cp backend/.env.example backend/.env
```
</Step>

<Step>
### Suba os containers

```bash
make up
```

Sobe a stack nas portas padrão (troque com `BACKEND_PORT`/`FRONTEND_PORT`).
</Step>

<Step>
### Gere a chave da aplicação

```bash
make art c="key:generate"
```

`make art` roda qualquer comando `php artisan` dentro do container do backend.
</Step>

<Step>
### Migre e crie um usuário de desenvolvimento

```bash
make fresh
```

Cria um usuário de desenvolvimento: `dev@finangui.test` / `password`.
</Step>
</Steps>

A documentação interativa da API (Scramble) fica em `http://localhost:8001/docs/api` enquanto `APP_ENV=local`.

## Targets do make no dia a dia

| Target | O que faz |
| --- | --- |
| `make up` | Sobe `db` (`:5432`), `backend` (`:8001`), `frontend` (`:5174`), o worker de fila e o scheduler. |
| `make art c="..."` | Roda um comando `php artisan` dentro do container do backend, ex.: `make art c="key:generate"`. |
| `make fresh` | Migra o banco do zero e cria um usuário de desenvolvimento (`dev@finangui.test` / `password`). |
| `make test` | Roda a suíte de testes Pest contra o banco `finangui_test`. |
| `make lint` | Roda Pint e Larastan no backend. |
| `make openapi` | Gera o schema OpenAPI em `backend/storage/app/openapi.json`. |
| `make types` | Regera o cliente tipado da API no frontend (`frontend/src/api/schema.d.ts`) a partir desse schema OpenAPI. Rode depois de mudar a API. |
| `make front-check` | Roda lint, typecheck e a suíte de testes do frontend. |

<Callout type="warn">
  `make test` roda contra o banco `finangui_test`, criado por `docker/postgres/init.sql` na primeira inicialização do volume. Se seu volume for anterior a isso, crie o banco à mão: `docker compose exec db createdb -U finangui finangui_test`.
</Callout>

O frontend também precisa de `npm install` no host para o editor e as ferramentas de TS; reconstrua sua imagem (ou a do backend, após mudança em `docker/php/**`) quando as dependências mudarem — só reiniciar não basta.

## Contribuindo

O finangui é um repositório público no GitHub; contribuições seguem o fluxo padrão de fork/branch/PR. As convenções reais do projeto vivem no `CLAUDE.md` do próprio repositório — a fonte da verdade, mantida atualizada conforme o código evolui.

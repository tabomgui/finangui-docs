finangui is a Laravel 13 API backend with Postgres (`backend/`) and a React/Vite/TypeScript frontend (`frontend/`). Everything runs in Docker, driven through a `Makefile` at the repository root.

## Requirements

- Docker
- Make

## Starting the stack

<Steps>
<Step>
### Create the backend env file

```bash
cp backend/.env.example backend/.env
```
</Step>

<Step>
### Start the containers

```bash
make up
```

Starts the stack on its default ports (override with `BACKEND_PORT`/`FRONTEND_PORT`).
</Step>

<Step>
### Generate the app key

```bash
make art c="key:generate"
```

`make art` runs any `php artisan` command inside the backend container.
</Step>

<Step>
### Migrate and seed a dev user

```bash
make fresh
```

Creates a dev user: `dev@finangui.test` / `password`.
</Step>
</Steps>

Interactive API docs (Scramble) are served at `http://localhost:8001/docs/api` while `APP_ENV=local`.

## Day-to-day make targets

| Target | What it does |
| --- | --- |
| `make up` | Starts `db` (`:5432`), `backend` (`:8001`), `frontend` (`:5174`), the queue worker and the scheduler. |
| `make art c="..."` | Runs a `php artisan` command inside the backend container, e.g. `make art c="key:generate"`. |
| `make fresh` | Migrates the database from scratch and seeds a dev user (`dev@finangui.test` / `password`). |
| `make test` | Runs the Pest test suite against the `finangui_test` database. |
| `make lint` | Runs Pint and Larastan on the backend. |
| `make openapi` | Generates the OpenAPI schema at `backend/storage/app/openapi.json`. |
| `make types` | Regenerates the frontend's typed API client (`frontend/src/api/schema.d.ts`) from that OpenAPI schema. Run this after changing the API. |
| `make front-check` | Runs the frontend's lint, typecheck and test suite. |

<Callout type="warn">
  `make test` runs against `finangui_test`, created by `docker/postgres/init.sql` on first volume init. If your volume predates it, create it by hand: `docker compose exec db createdb -U finangui finangui_test`.
</Callout>

The frontend also needs `npm install` on the host for editor/TS tooling; rebuild its image (or the backend's, after a `docker/php/**` change) when dependencies change — a restart alone won't do it.

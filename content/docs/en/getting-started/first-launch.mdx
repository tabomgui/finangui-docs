---
title: First launch
description: What to expect the first time you log into a freshly installed finangui instance.
---

Open your domain in the browser and log in with the email and password you set when running `php artisan user:create`. You land on **Início** (Home), the dashboard screen.

## What's already there

Creating the user already seeds a default set of categories for it — common Brazilian expense categories (**Moradia** / Housing, **Alimentação** / Food, **Transporte** / Transport, **Saúde** / Health, and others, each with a few subcategories), income categories (**Salário** / Salary, **Freelance**, **Rendimentos** / Investment income, among others), and the categories used internally for transfers, statement payments and investment moves. You don't need to create categories from scratch before you can start categorizing entries.

Nothing else is pre-seeded. There are no accounts and no transactions yet, so **Início** opens in an empty state: no balance, no spending breakdown, nothing pending.

## First steps

With no accounts yet, there's nothing to show a balance for and nothing to attach a transaction to. The natural first step is to set up your **Contas** (Accounts) — checking, savings, cash or credit card — before anything else. See [Accounts](/docs/features/accounts) for how balances are computed and how a credit card account differs from the others.

Once you have at least one account, you can either add entries by hand, import a statement (**Importar extrato**), or connect a bank through **Configurações** (Settings) if you want transactions to sync automatically. Review the seeded **Categorias** (Categories) at that point too — rename, remove or add to them to match how you actually want to track spending; nothing stops you from adjusting them before or after you start logging transactions.

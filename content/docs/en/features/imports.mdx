The **Importar extrato** (Import statement) screen (`/importar`) brings a bank statement file into finangui. Nothing is saved until you review and confirm a preview.

![The import statement screen](/screenshots/imports.png)

## Supported formats

<Tabs items={['Inter', 'Nubank', 'C6', 'OFX']}>
<Tab value="Inter">
CSV export of an Inter checking account statement.
</Tab>
<Tab value="Nubank">
Two CSV formats: **Nubank (conta)** for checking, **Nubank (cartão)** (Nubank card) for credit card.
</Tab>
<Tab value="C6">
CSV export of a C6 checking account statement.
</Tab>
<Tab value="OFX">
A generic OFX file, for banks without a dedicated CSV format above.
</Tab>
</Tabs>

Export the statement from your bank, then upload it. **Detectar automaticamente** (detect automatically) picks the format for you.

## Uploading a file

- **Conta** (Account) the statement belongs to.
- File: `.csv`, `.ofx`, or `.txt`, up to 2 MB.
- Submitting opens the **Prévia da importação** (Import preview) screen.

## Preview before anything is saved

![Preview with imported rows](/screenshots/imports-preview.png)

Each line gets a label:

- **Nova** (New) — not seen before.
- **Já importada** (Already imported) — locked in, can't deselect.
- **Atualiza** (Updates) — refreshes an existing entry.
- **Substitui parcela prevista** (Replaces projected installment) — real replaces projected.
- **Casa com lançamento manual** (Matches manual entry) — adopts your manual entry.
- **Confirma pendente** (Confirms pending) — replaces an unconfirmed entry.

Every actionable row has a checkbox, checked by default. Unparseable lines show up separately, with the reason.

## Confirming

- Button label shows how many entries are checked.
- Confirming re-checks the matching from scratch.
- The whole batch commits as one unit — all or nothing.
- **Cancelar** (Cancel) discards the batch.

## Reverting an import

- Only the most recently completed import per account can be reverted.
- **Reverter** (Revert), on the **Importações recentes** (Recent imports) card, deletes what it created and restores what it matched or updated.

<Callout type="warn">
  A manual edit made after the import, to a field the import touched, gets overwritten too.
</Callout>

## Categorization and transfers

- Imported entries get the same automatic categorization as manual ones (rule, then history). See [Categorization](/docs/features/categorization).
- Transfer detection runs right after confirmation. See [Transfers](/docs/features/transfers).

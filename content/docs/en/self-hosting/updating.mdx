---
title: Updating
description: How to pull and rebuild a self-hosted instance to a newer version.
---

Updating a self-hosted instance means pulling the latest code and rebuilding the Compose stack:

<Steps>
<Step>
### Pull the latest code

```bash
git pull
```
</Step>

<Step>
### Rebuild and restart

```bash
docker compose -f docker-compose.prod.yml --env-file backend/.env up -d --build
```

This rebuilds any service whose image changed and restarts the stack with the new code.
</Step>
</Steps>

<Callout type="info">
  Migrations run automatically on start, as covered in [Installation](/docs/getting-started/installation) — there's no separate migration step to run after an update.
</Callout>

Back up the database before updating if the change is large or you're jumping several versions at once — see [Backup](/docs/self-hosting/backup).
